# 绝区零抽卡概率计算器 (ZZZdrawing)

一款原生 Android 端《绝区零》（Zenless Zone Zero）调频概率与抽卡规划应用（Kotlin + Jetpack Compose + Material 3）。

## 主要功能

### 模式一：目标配置算抽数
- 选择目标角色命座（不抽角色、`0命 ~ 6命`，注：`0命` 需抽 1 个角色、`x命` 共需 `x + 1` 个角色）与专武精炼（`0精/不抽 ~ 5精`）。
- 可选填写限定角色池/音擎池当前已垫抽数与大小保底状态。
- 输出两大产物：
  1. **绝区零抽卡分位表**：展示 `10% / 25% / 50% / 75% / 90% / 95% / 99%` 概率所需抽数及数学期望（覆盖 `影画0 ~ 影画6` 系列对比行）。
  2. **概率分布钟形曲线图**：可视化单抽毕业概率钟形分布与累计达成率 S 曲线，支持手势触摸/滑动准星与滑块步进查看任意抽数的精确概率。

### 模式二：现有抽数算配置
- 支持输入**现有菲林**（160=1抽）、**加密母带**与**现有信号余波**（20=1抽）汇总总抽数。
- 支持填写角色池/音擎池已垫抽数与大小保底。
- 支持默认抽卡顺序（先抽 0 命 → 专武 1 精 → 1~6 命 → 2~5 精）与**自定义抽卡顺序编辑器**。
- 输出当前抽数可达到的配置概率分布（展示「恰好停在该配置」与「至少达到该配置」双概率），默认仅显示 **3 西格玛（±3σ ≈ 99.73%）** 以内的主要可能性（可展开查看长尾项）。

### 自定义打折抽卡（副产物信号余波换抽）
- 支持开启将抽卡副产物信号余波兑换成加密母带继续抽卡（`20 余波 = 1 抽`）。
- 支持自定义开关：**四星（A级）代理人是否满命**、**常驻五星（S级）代理人是否满命**。
